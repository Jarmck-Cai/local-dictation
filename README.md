# 轻述 · Local Dictation

Windows 通用语音输入工具。本地 SenseVoice INT8 识别中英混合语音，可用 Claude 整理文字，也可切换本机整理服务或关闭整理。

按住 **F8** 说话，松键后将结果一次粘贴到当前光标位置，由使用者自行发送。适用于编辑器、终端、聊天等普通输入场景，无需按应用安装插件。

当前预览版 **0.1.12-beta.2**，加入会议录音试用并默认选中首个麦克风和播放设备；此前日用版为 **0.1.11**。基于 [Handy v0.9.8](https://github.com/cjpais/Handy/releases/tag/v0.9.8) 改造，桌面端使用 Tauri 2、Rust 和 React，运行不依赖 Python。来源与许可见 [UPSTREAM.md](desktop/UPSTREAM.md) 和 [LICENSE](LICENSE)。

会议 Beta：侧栏进入「会议」，选择麦克风及会议实际使用的播放设备，点击「开始录音」，结束后在本机转录；切换页面或隐藏主窗口仍继续录制，会议录制期间普通按键听写暂停。保留两路原音七天并可导出，文本按「麦克风／电脑声音」标记录音来源。外放回声、重复文字、接话与说话人区分尚未完成真实会议验收，不将这些来源标签当作可靠身份识别；真正重叠讲话后续改进。电脑声音包含所选设备上其他应用的播放。安装或启动应用不会自动开始会议录制。

## 功能

- 本地识别，录音不上传；Claude 模式发送转写文字及相关词库提示。
- 浅绿色紧凑列表：首页显示最近15条记录，完整历史按30条分页并搜索全部保留原文和终稿；展开后可直接“提供纠正”，翻页保留草稿和确认状态。
- 最近七天使用量与预计节省时间，估算口径和有效样本数可查看；缺少时长的旧记录不编造省时数值。
- 默认轻整理、断句和自然分段，可调整强度，始终以保留事实和原意为目标。
- 云端短文等待预算三秒，随长度增加至最多八秒；超时回退本地，连续失败后自动暂停，可手动恢复。
- 常用词按不同保留转录自动收集，无需逐词确认；支持搜索、点赞、删除和恢复。新词表及标签不参与纠错或云端提示。
- 已有已确认词库和主动提交修改稿流程独立保留，明确确认后才参与纠正；可编辑、启停，并查看本次本地纠正命中。
- 显示识别、整理、粘贴及总等待时间、近期统计和处理边界资源快照。
- 独立 Windows 程序，设置中可开启登录后自动启动到托盘，默认关闭。
- Ctrl+Shift+F9 手动补贴最近终稿，不重新识别、整理或发送；尽量恢复支持的原剪贴板内容，无法恢复时留下本次终稿，不因特殊格式取消输入。
- Windows 自动输入也使用保护事务，观察读取后再恢复原剪贴板；未确认输入时保留结果，不自动重复粘贴。
- 自动输入失败时显示居中的补救窗口；复制成功约1.5秒后收起，复制失败仍保留。恢复失败有单独提示。
- 区分按键未松开与按键状态不可用，明确提示补贴方式；对满足原始输入核对条件的未绑定扩展键残留作兼容，保留真实按键保护。
- 录音时临时静音播放并恢复；录音本地缓存七天，安装版配置当前用户每日清理任务。

默认快捷键：F8 按住录音，Esc 取消，Ctrl+Shift+F8 复制最近结果，Ctrl+Alt+F8 暂停或恢复云端整理，均可配置。输入位置以文字实际粘贴时的当前光标为准，已有选区会被替换。

## 使用与构建

使用流程、凭据配置和数据策略见 [使用说明](docs/desktop-usage.md)。源码在 `desktop/`，Windows 构建需要 Rust stable、Visual Studio 2022 C++ Build Tools、Windows SDK 和 CMake。

在项目根目录的 PowerShell 中运行：

```powershell
./scripts/prepare-desktop.ps1
./scripts/build-desktop.ps1
./scripts/package-desktop.ps1
```

准备脚本下载并校验构建资源与模型，来源及摘要见 [固定资源](desktop/RESOURCES.md)。模型、依赖缓存和生成的安装包不存入 Git。构建产物位于 `outputs/desktop/`，可用 `run-desktop.cmd` 启动本机已安装版本或该目录的免安装版本。

桌面端 Claude 密钥在界面本机配置，使用 Windows 当前账户保护；本机整理需自行启动兼容服务。初次克隆不含任何密钥或用户数据。可选的 Python 测量工具见 [验证说明](docs/validation.md)，与桌面运行时分开。

## 开发状态

0.1.11 增加最近记录、完整历史搜索和极简自动词表。词表次数只统计当前保留记录，收录不代表识别正确；中文词典与英文技术词提取可能遗漏专名。沿用Windows按键保护与错误提示，针对经过原始输入核对的未绑定F13–F24残留作兼容；普通按键、修饰键、真实扩展键及配置过的快捷键继续受保护，无法确认来源的状态仍会拒绝输入。沿用剪贴板尽力恢复、新复制优先、轻述紧凑界面、浅绿图标与窗口居中。观察到读取不能证明目标已显示文字，实际识别质量、松键到屏幕落字时间及不同应用的输入兼容性仍需日常反馈。资源数值仅来自当前进程的处理边界，内存不是连续采样峰值，CPU时间不是整机占用率。词库提取及整理护栏使用规则，无法保证发现所有术语或避免每次语义改写。
