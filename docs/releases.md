# 版本记录

本项目基于 Handy v0.9.8，保留上游 MIT 许可及固定来源说明。此前本机没有 Git 提交，历史版本按留存源码备份导入，提交时间为导入时间。

## 0.1.5

- 新增可配置Ctrl+Shift+F9主动补贴最近终稿，等待按键释放、忙时拒绝、一次手势一次输入；不重新识别、调用云端或发送消息。
- 独立保护式剪贴板事务：写前完整备份，无法安全恢复的格式拒绝；恢复时在锁内核对序号与归属，保留并发新复制内容，错误与取消明确反馈。
- coordinator串行许可隔离补贴与自动输入，保护旧快捷键配置并提示新组合键冲突。
- 自动输入链路与模型保持不变，保留原明确复制入口。

## 0.1.4

- 首页增加当前用户登录启动开关，默认关闭，启动到托盘；正确引用含空格路径，读取实际状态、传播失败并保护其他安装的启动项，卸载按归属移除。
- 首页增加近期耗时、较慢记录、回退原因和取消/无音频汇总；新增当前进程处理边界资源快照，保持旧耗时记录兼容。
- 已学词条支持编辑术语、别名、上下文及启用/停用；停用项不纠正或发送云端提示，事务失败保留旧项。
- 展示本次实际本地纠正命中，仅进程内保留，下一次听写清空。
- 统一用户取消入口，避免取消计数缺失、重复记录和未领取凭据残留。

## 0.1.3

- 默认轻整理与自然分段，提供三档整理强度。
- Claude 按文字长度设置三至八秒预算，超时回退本地；连续三次超时或网络失败暂停十分钟，支持界面与快捷键暂停、恢复。
- 记录识别、整理、粘贴及总等待时间和回退原因。
- 本地提取术语及搭配候选，经确认后生效；历史中可主动提交修改稿作为本地样本。
- 修复上下文误替换、冷却状态及记录保留问题；完成离线检查、原生构建和保留数据升级验证。

## 0.1.2

- 安装版启用当前用户每日音频清理任务，卸载移除；保持七天缓存策略。
- 清理任务使用普通权限，只处理专用录音目录，不录音、不联网。
- 修复安装所有权及数据目录识别，保留程序内启动和日常清理。

## 0.1.1

- 修复录音浮层进度和故障提示关闭后的状态恢复。
- 改进安装清理任务检查。

## 0.1.0

- Windows 通用语音输入首版：本地 SenseVoice INT8、Claude／本机／关闭整理切换。
- 全局按住录音、播放静音恢复、当前光标一次粘贴、取消及复制最近结果。
- 本地录音七天缓存及历史管理。

## 源码存档范围

`v0.1.2` 是从开发前备份恢复导入的应用源码：两棵完整前后端 src 树及四份版本元数据来自备份，其他未变构建文件沿用工作副本，公开说明在导入时补充。该标签不包含当时全部私人文档或根目录验证工具，也不表示重新构建验证了旧安装包。

`v0.1.3` 对应当前应用源码及公开开发资料。0.1.0、0.1.1 只有局部源码备份和本机安装包，因此仅记录版本演进，不创建声称精确还原的源码标签。
