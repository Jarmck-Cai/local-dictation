# 版本记录

本项目基于 Handy v0.9.8，保留上游 MIT 许可及固定来源说明。此前本机没有 Git 提交，历史版本按留存源码备份导入，提交时间为导入时间。

## 0.1.12-beta.2

- 修复会议页初始设备选择为空、必须手动选择后才能开始的问题。麦克风与播放设备加载后分别默认选中第一项；下拉框显示、按钮有效性与实际提交使用相同的设备ID。
- 有效的手动选择在刷新时保留；设备消失时回落到当前列表首项，空列表仍不可开始。默认选择不自动录音，也不改变正在录制会议的音源。
- 更新准备提示，保留播放设备核对及录制期间设备固定的说明。其余会议Beta限制沿用上一版。

## 0.1.12-beta.1

- 新增 Windows x64 会议预览：显式选择麦克风与会议播放设备后开始双轨录制，可后台持续，结束后本机转录，支持取消、重试、恢复及音频／文字导出。会议录音本地保留七天，不上传音频、不自动输入会议正文或收集到词表。
- 录制期间普通按键听写暂停并有明确提示，结束录制后可重新使用；会后识别共用本地模型，可能等待处理。安装和打开会议页不会自动开始录音。
- 本版供真实会议试用，声音来源暂标为“麦克风／电脑声音”，不承诺可靠区分本人和远端。界面及文字导出标注外放可能重复或归属不准，未完成或中断结果有对应提示；保留原音便于回听和后续重新处理。电脑声音也会包含所选设备上其他应用的播放。
- 生产队列与存储已通过受控合成源两小时墙钟验证；真实设备两小时连续录制、外放准确率和正常接话完整性仍待实际会议验证。真正双讲及远端多人区分后续实现。本次为预发布，不替代正式版验收。

## 0.1.11

- 首页固定显示最近15条，完整历史在同页按30条分页；搜索覆盖全部保留记录的原文和终稿，不受统计最多300条预取范围限制。关键词按字面匹配，新增记录不会挤乱当前页，切换查询后丢弃迟到结果。
- 纠正草稿、提交状态及候选确认结果按记录保留，翻页、搜索和返回最近记录可继续处理；删除对应历史后清理相关界面状态。
- 新增极简自动词表：在至少两条当前保留转录中出现的词自动展示，无需日常确认。支持搜索、点赞、删除和恢复；点赞词可在来源不足时保留，删除后不会被回填或新记录自动恢复。
- 词表使用本地中文分词和英文技术词提取，后台幂等收集已有及新记录，历史改写或删除清除旧观察。记录数不代表终身使用次数或正确率，自动收集可能包含识别错误、遗漏专名。
- 新词表及标签独立存储，不改变正文、不进入云端提示；已有已确认词库和主动纠正确认流程继续兼容。数据库仅追加第七迁移，保留旧历史和确认词条。

## 0.1.10

- Windows按键检查增加扩展功能键的原始输入核对：普通按键、修饰键和已配置的快捷键继续受保护；仅对有已松开基线、没有真实按下且经过稳定核对的未绑定F13–F24系统残留状态作兼容。不自动抬键，也不直接忽略F22。
- 自动输入在借用剪贴板前短暂等候按键释放，最终输入前仍核对当前按键、快捷键配置及剪贴板授权；不自动重复粘贴。
- 短暂查询超时或新键盘事件到来时，只撤销本次核对，下一次可重新确认；原始数据读取、注册归属或容量异常仍保守阻止。手动补贴也在借用剪贴板前取得输入锁，防止等待时误贴新复制内容。
- 自动输入与原生补救窗口明确区分“按键尚未松开”和“无法读取按键状态”，提供松键后补贴或复制的指引，不再将它们显示为笼统失败。
- 键盘观察器仅保存扩展键当前状态，不保存字符、按键序列或设备名称，随应用运行；清理及无界面转录入口不启用。启动前已按下、设备或会话重置及观察器异常等无法确认的状态继续保守处理，不能保证自动解除所有来源不明的历史状态。

## 0.1.9

- Windows自动输入与手动补贴改为尽力恢复剪贴板：支持的文字、HTML、RTF、PNG、DIB、位图与普通文件列表继续备份；跳过未知、不可读取或超出64MiB／64项备份预算的格式，不再因此拒绝整次输入。
- 原内容非空但没有可恢复的有效内容时，剪贴板留下本次转录；部分原内容写回成功时保留这些原内容，全部有效内容写回失败时才尝试留下本次转录，避免旧富文本与新文字混在一起。保留原本空剪贴板的处理、期间新复制优先、取消和单次输入规则，不自动重发不确定的输入。
- 设置明确显示“尽量恢复原内容”，不再承诺所有剪贴板格式完整保留。真实系统锁定、发布或输入失败仍会报告，不能因采用尽力恢复而冒充输入成功。
- 主窗口启动时居中，后续打开保留用户拖动位置；窗口运行时图标显式使用轻述PNG，应用、安装资源和托盘统一浅绿底板声波光标，托盘状态变化保留彩色图标。
- 新增合成格式跳过及恢复回退检查；合成读取不等同于目标应用实际落字，截图与文件在具体应用中的恢复仍需日用反馈。

## 0.1.8

- 修复0.1.6引入、0.1.7仍存在的自动输入拦截：Windows在CloseClipboard完成时可生成文本派生格式并递增版本号。保护事务现在在发布真正结束后记录版本，避免将自身正常变化误判为新的复制。
- 保留发键前同锁核对版本及本次唯一所有者、并发新复制优先和单次输入规则；不通过自动重发或恢复旧版固定60ms还原来掩盖错误。
- 新增提取实际Win32发布、输入前校验及结算代码的合成回归，覆盖系统格式转换与真实新复制的区别。它不操作系统剪贴板，也不代表目标应用已落字。

## 0.1.7

- 修复剪贴板备份兼容性：Windows合成文本在内容不变时可返回新的内存句柄，0.1.6误按句柄身份拒绝。改为锁内核对原始复制长度和内容，保留未知格式、预算、真实内容变化及并发复制护栏；备份分配清零，避免额外容量包含未初始化字节。
- 补救窗口标题、正文及按钮居中，沿用录音标记的屏幕中心和边缘锚点；复制成功1500ms后收起，失败继续保留，迟到复制和计时回调不会关闭新录音或新故障。
- 原生补救窗口也保留受限错误原因，明确区分恢复失败和输入未确认，未知字段不回显。

## 0.1.6

- 使用“轻述”名称和原创声波光标标志，保留浅绿色。最近转录采用紧凑列表，复制常驻，展开后直接填写并“提供纠正”；词库、统计、设置独立呈现。
- 首页显示最近七天最多300条的使用量和预计省时；录音请求至松键时长新增为可空元数据，旧记录缺失时不参与省时估算。历史列表继续按需分页，不受统计样本上限限制。
- 修复Windows自动输入固定短延时恢复剪贴板的竞态：目标稍晚读取时可能得到原剪贴板中的上一段文字。自动输入改在后台使用保护事务，观察读取再结算，当前任务持有许可直到结算结束。
- 未观察读取、所有权被新复制取代、取消和失败不冒充成功，不自动重试不确定的输入；无法安全备份时拒绝。复制偏好在同一所有权检查中保留真实文字，用户新复制优先；恢复失败明确提示检查剪贴板。
- 保留原安装目录、二进制、应用标识、Data及登录/每日清理归属，支持既有安装升级。读取观察仍不能证明目标屏幕落字。

## 0.1.5

- 新增可配置Ctrl+Shift+F9主动补贴最近终稿，等待按键释放、忙时拒绝、一次手势一次输入；不重新识别、调用云端或发送消息。
- 独立保护式剪贴板事务：写前完整备份，无法安全恢复的格式拒绝；恢复时在锁内核对序号与归属，保留并发新复制内容，错误与取消明确反馈。
- coordinator串行许可隔离补贴与自动输入，保护旧快捷键配置并提示新组合键冲突。
- 自动输入链路与模型保持不变，保留原明确复制入口。

## 0.1.4

- 首页增加当前用户登录启动开关，默认关闭，启动到托盘；正确引用含空格路径，读取实际状态、传播失败并保护其他安装的启动项，卸载按归属移除。
- 首页增加近期耗时、较慢记录、回退原因和取消/无音频汇总；新增当前进程处理边界资源快照，保持旧耗时记录兼容。
- 已学词条支持编辑术语、别名、上下文及启用/停用；停用项不纠正或发送云端提示，事务失败保留旧项。
- 展示本次实际本地纠正命中，仅进程内保留，下一次听写清空。
- 统一用户取消入口，避免取消计数缺失、重复记录和未领取凭据残留。

## 0.1.3

- 默认轻整理与自然分段，提供三档整理强度。
- Claude 按文字长度设置三至八秒预算，超时回退本地；连续三次超时或网络失败暂停十分钟，支持界面与快捷键暂停、恢复。
- 记录识别、整理、粘贴及总等待时间和回退原因。
- 本地提取术语及搭配候选，经确认后生效；历史中可主动提交修改稿作为本地样本。
- 修复上下文误替换、冷却状态及记录保留问题；完成离线检查、原生构建和保留数据升级验证。

## 0.1.2

- 安装版启用当前用户每日音频清理任务，卸载移除；保持七天缓存策略。
- 清理任务使用普通权限，只处理专用录音目录，不录音、不联网。
- 修复安装所有权及数据目录识别，保留程序内启动和日常清理。

## 0.1.1

- 修复录音浮层进度和故障提示关闭后的状态恢复。
- 改进安装清理任务检查。

## 0.1.0

- Windows 通用语音输入首版：本地 SenseVoice INT8、Claude／本机／关闭整理切换。
- 全局按住录音、播放静音恢复、当前光标一次粘贴、取消及复制最近结果。
- 本地录音七天缓存及历史管理。

## 源码存档范围

`v0.1.2` 是从开发前备份恢复导入的应用源码：两棵完整前后端 src 树及四份版本元数据来自备份，其他未变构建文件沿用工作副本，公开说明在导入时补充。该标签不包含当时全部私人文档或根目录验证工具，也不表示重新构建验证了旧安装包。

`v0.1.3` 对应当前应用源码及公开开发资料。0.1.0、0.1.1 只有局部源码备份和本机安装包，因此仅记录版本演进，不创建声称精确还原的源码标签。
