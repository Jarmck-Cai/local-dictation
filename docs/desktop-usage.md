# Windows 内测版使用说明

版本：轻述 0.1.9。基于固定 Handy v0.9.8，源码与许可在 `desktop/`。安装目录、开始菜单及程序文件仍沿用 Local Dictation，便于保留数据升级。

## 开始使用

安装后可从开始菜单的 Local Dictation 或桌面快捷方式启动。源码工作区也提供 `run-desktop.cmd`：依次查找项目内的 `installed/Local Dictation/`、当前用户默认安装目录，以及 `outputs/desktop/Local Dictation/` 中的程序。

安装包为 `outputs/desktop/Local Dictation_0.1.9_x64-setup.exe`。同目录可能保留旧版，请按版本号选择。免安装目录中的 DLL 与 `resources` 必须和程序一起保留。

程序有托盘图标。关闭设置窗口后仍留在托盘；从托盘菜单退出才完全结束。首次启动会从附带资源准备本地模型并预加载，界面显示准备状态。

程序独立于 Codex，日常可从开始菜单或桌面快捷方式启动。侧栏底部“设置”中的“登录 Windows 后自动启动”默认关闭，开启后使用当前用户的登录启动项，直接启动程序到托盘，无需 Codex、终端或额外常驻服务。开关读取系统实际状态；注册失败时保留旧设置并提示。Windows 任务管理器禁用的启动项不会在普通启动时强行恢复，用户在软件中明确开启可以重新启用。卸载仅移除指向本安装程序的启动项；另一安装或便携副本的项目保留。

1. 将光标放到想输入的位置，按住 **F8** 说话，松键结束；单次最长三分钟。
2. 录音期间默认临时静音播放，停止捕获后恢复原状态。识别与整理在松键后处理。
3. 文字准备好后，向**实际输入时的当前光标**粘贴一次；等待期间切换窗口也跟随新位置。已有选区会按普通粘贴替换。不自动按 Enter，不发送消息或执行终端命令。
4. **Esc** 取消当前录音或处理。输入失败时从界面取用，或按 **Ctrl+Shift+F8** 复制最近完成的正文，再自行粘贴。

**Ctrl+Alt+F8** 暂停或恢复云端整理，也可在“设置 → 文字整理”操作。暂停会中止尚未完成的云端整理，回退本地结果；恢复从下一次录音生效。所有快捷键均可在设置修改。不需要为 Codex、Claude Code、微信安装插件或单独配置。

## 自动输入未出现时

补救窗口与录音标记沿用同一居中锚点，标题和按钮居中。复制成功后显示“已复制”，约1.5秒自动收起；复制失败会继续显示，可重试或手动关闭。新的录音、错误或关闭会取消旧的收起回调。

将光标点回目标输入框，按 **Ctrl+Shift+F9**（可配置）并松开全部按键，补贴最近已完成的最终正文。使用已有本地结果，不重新识别或整理，不发送消息。每次按键只发起一次补贴，长按不连贴；正在录音、处理或输入时拒绝，不排队贴旧段。按键释放超过两秒会放弃，松开后重新按；长按超时后的第一次完整手势可能只解除锁定，界面会提示再按。

补贴短暂借用系统剪贴板，结束后尽量恢复支持的原内容；期间用户或其他应用产生的新复制内容优先保留。可备份常见文本、HTML、RTF、PNG、DIB、位图与普通文件列表，备份预算为64MiB、最多64项；不支持、不可读取或超预算的格式会跳过，不会因此取消输入。部分原内容恢复成功时保留这些原内容，不混入本次转录；非空原内容没有任何可用备份、或全部有效内容写回失败时，则尝试留下本次终稿，这也适用于未启用“复制到剪贴板”的情况。文件剪切、虚拟附件和软件专有对象不保证完整恢复。原Ctrl+Shift+F8仍为明确复制，会替换剪贴板。

正常Windows自动输入也采用同一尽力恢复事务：当前正文准备后只发起一次输入，观察到读取并经过短暂安静期后再结算；读取观察窗口上限为三秒，不等于整个事务的总时限。未观察到读取或期间出现新的复制时，标记输入未确认，不自动重试。启用“复制到剪贴板”偏好时，会在同一所有权检查中保留当前终稿，用户新复制仍优先。读取信号不能证明输入框已经显示文字；请先检查，避免手动补贴造成重复。恢复失败会尝试留下本次终稿；如果系统连这个回退也不允许，仍明确提示失败。已有选区仍按普通粘贴替换；更高权限或特殊输入控件可能不接受模拟输入。

新组合键若与已有快捷键冲突，旧快捷键优先保留，设置中提示修改补贴组合键；原录音、取消、复制和云端暂停设置不变。

## 整理与凭据

默认本地 SenseVoice INT8 识别，Claude Haiku 5.5 整理转写文字及相关词库提示，录音不上传。“设置 → 文字整理”可切换“Claude”“本机”“关闭整理”。模式和凭据在开始录音时固定，本机失败不会改用云端。

首次使用 Claude 整理时，请在文字整理设置中填入自己的 Claude API 密钥并保存。密钥通过 Windows 当前账户保护，保存后只显示是否已配置；请勿把真实密钥放进聊天、截图或 Git。整理配置和受保护凭据保存在 Windows 账户配置目录，便携模式也不会将它们迁入 `Data/`，交付文件不附带凭据。未配置密钥时仍可本地识别并回退原始转写。

本机整理需自行运行兼容服务，填写 loopback 地址和模型名；工具不会自动下载或常驻本地大模型。本机整理默认等待上限为八秒。超时、服务错误、数字/人称/参数校验未通过时采用本地转写（保留已确认词库纠正），不自动重试。

整理强度可选“贴近原话／轻整理／清晰表达”，默认轻整理。自然分段默认开启：根据内容关系断句和分段，保留原意、人称、数字、否定、条件、确定程度和技术文本。最高档也不会要求扩写或增加事实；自动护栏和提示不能保证每次语义完全正确，原始转写仍可取回。

Claude按非空白字符设置等待预算：600字以内三秒，此后每字增加10毫秒，最多八秒。连续三次超时或网络失败后自动暂停十分钟，期间直接使用本地转录及已确认词库；到期后在下一次正常录音尝试恢复，不后台探测、不切其他供应商。可显式提前恢复；手动暂停则一直保持至主动开启。已有本机整理不受云端暂停影响。

“使用统计”和单条记录详情显示识别、整理、输入及总等待，包含回退原因；总等待从软件处理松键开始至输入流程结算，不等同物理松键到屏幕显示。新记录增加录音请求至松键的单调时钟时长，包含设备就绪等待和静音。耗时记录不含正文、密钥或录音，最多300条，七天到期，在正常启动/每日运行维护/读取时清理。

首页显示最近七天最多300条保留记录的转录次数、生成文字量和预计省时，不称确认落字量。省时按中文60字/分钟、英文40词/分钟的参考打字速度，减去本条录音和处理时间，每条不低于零；只纳入完整时长记录，显示样本数，旧记录缺失时长时不估算。这是基准估算，不是测得的个人打字速度或真实节省保证。历史列表继续按需分页，不受统计上限限制。

“使用统计”汇总软件完成、中位等待、较慢记录、云端回退及取消/无音频次数。无音频、取消和输入未确认不计入完成耗时；不足五个完成样本时提示样本较少。处理边界资源仍仅为当前进程工作集和CPU时间，内存不是连续采样峰值，CPU不是整机占用率；旧记录没有资源字段也可读取，没有常驻采样线程。

## 词库学习与修改稿

词库页保留手动添加入口，并显示从新转录中本地提取的术语、缩写和常用搭配候选。候选先确认才生效，可以忽略；已确认的学习词条可以删除。规则提取不能保证发现所有中文人名和专业词。

修改较多时，在“最近转录”找到并展开对应记录，直接填写改好的完整文字，再点“提供纠正”（最多8000个字符）。用于生成词库建议，不修改这条记录。收起记录后保留本次窗口中的未提交草稿；候选先确认才生效。工具仅在本机比较转录、整理和修改稿，不读取其他软件的修改、不主动读取剪贴板、不上传样本或重新向目标窗口输入。大幅改写或难以判断的变化只保留样本，不强行生成替换规则。

同音、近音别名只在确认且上下文合适时应用。上下文限定同分句、命中左右各24字符，保留完整英文词；不跨句用技术语境替换人名。词库读取失败时保留转录。云端暂停期间本地词库和样本处理仍可用，但不提供云端语义整理与分段。

已确认词条可编辑术语、别名与上下文，也可临时停用后再启用。停用后不参与本地纠正或云端提示。更改有冲突或校验失败时保留原词条。词库页显示最近听写真正发生的本地替换及次数；这些命中只保存在进程内，新听写时清空，退出后不保留，不把相关云端提示词当作纠正命中。

样本、未确认候选随对应文字历史删除或过期清理，重试替换原历史正文时也清理；已确认词条独立保留，用户可删除。收藏文字可能保留样本，但不会延长音频期限。

## 数据与恢复

音频只存在本地，七天到期；收藏文字不延长音频期限。原文与最终文默认保留七天，手动收藏的文字可保留，音频仍到期删除。首页与历史页可复制、删除，最近结果快捷键只复制而不重新识别。

默认将录音、历史和模型缓存保存在 Windows 当前账户的应用数据目录，可在设置中查看实际位置。便携模式将这些数据放在可执行文件旁的 `Data/`，录音位于 `Data/recordings/`。启用便携模式需在程序旁放置名为 `portable` 的文件，内容为 `Handy Portable Mode`；保留该标记和 `Data/`，确保程序与每日清理任务使用相同数据。录音、历史、词库及凭据都是个人数据，不应随源码或发布包分发。

程序在启动时补清理，运行期间每天清理过期音频，包含孤立及临时音频，且不会沿链接离开专用录音目录。超过七天的录音在下一次清理时删除。

**安装版**另配置当前用户的每天清理任务，在程序完全退出后也可清理。安装约五分钟后首次执行，之后每24小时执行。任务以普通权限调用本工具的“仅清理”入口，不录音、不联网、不准备识别模型，也不修改文字历史；卸载时移除本安装所属任务。创建失败时安装器会提示，程序内清理仍可用。关机、休眠或未登录时无法按时执行，恢复可运行后补清理，不会唤醒电脑。

**免安装版**不会自动注册任务，完全退出期间到期的录音在下次启动补清理。

安装路径包含 `%` 时，系统可能将它作为环境变量展开，因此安装器会提示无法启用定时清理。可换用不含 `%` 的目录；程序内清理仍可使用。

录音取消、普通失败与正常退出会尝试恢复同一播放设备的原静音状态；强杀、断电及切换播放设备有边界，无法保证所有情况下自动恢复。发生故障时可手动恢复系统音量并从历史取回文字。

错误提示支持复制和关闭；在录音或处理期间关闭提示后，继续显示当前阶段。关闭提示不会取消录音或重试输入。

## 检查边界

离线开发检查使用合成文字、假密钥、本机假服务、临时文件和状态机。实际准确率、松键到落字时间、内存及应用输入兼容性受设备和输入场景影响，需在目标环境确认；独立 Python 验证工具的数据不能直接作为本程序测量值。

## 从源码构建

安装 Rust stable、Visual Studio 2022 C++ Build Tools 与 Windows SDK。运行 `scripts/prepare-desktop.ps1` 准备固定构建资源，再运行 `scripts/build-desktop.ps1`，最后 `scripts/package-desktop.ps1`。可用 `-CheckOnly` 检查，`-PortableOnly` 只构建免安装程序。

准备脚本校验官方资源摘要；运行时不需要 Python、Bun、Rust 或单独的终端服务。
